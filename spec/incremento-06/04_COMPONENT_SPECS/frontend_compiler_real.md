# compilers/frontend_compiler.py — Compilers Reais (Frontend + Client)

## Objetivo
Gerar frontend funcional real e client TS alinhado ao OpenAPI.

## Entregáveis
- Páginas CRUD funcionais
- Formulários tipados
- Listagem
- Client TS gerado do OpenAPI

## Alinhamento obrigatório
- Se OAS muda → client muda.
- Se client quebra → Fix Loop entra.

## Critério de aceite (Dia 5)
- `npm run build` passa.
- TypeScript sem erros.
