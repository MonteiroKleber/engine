# Incremento-02 — Semana 4 (IR Canônico: Domain Modeler + IR Gate)

Este diretório contém a especificação organizada e prompts em fases para implementar a Semana 4 usando o Claude Code.

## Como usar
1) Leia `00_CONTEXT.md` (objetivo, escopo e critérios de aceite).
2) Verifique deltas de estrutura e convenções em `01_REPO_LAYOUT.md`.
3) Confirme dependências/config em `02_DEPENDENCIES.md` e `03_CONFIG_SPEC.md`.
4) Implemente componente a componente usando `04_COMPONENT_SPECS/`.
5) Use os prompts prontos em `prompts/` (um por dia/fase).
6) Valide com os critérios em `05_TEST_PLAN.md`.

## Princípios
- Determinístico (sem SDK de LLM nesta semana).
- Foco em IR canônico + gates (schema + policy) + versionamento.
- Não inferir entidades não citadas no SRS.
