# Expansão (Engine) — Roadmap de Runtime/Dispatcher

Esta pasta define um plano em fases para **expandir** o runtime do engine (principalmente dispatcher + state store + contracts)
para suportar bundles reais além do fluxo Finance (ex.: Bazari Social/Bazchat/Moderação), mantendo:

- `ENGINE_INSTALL_MODE=prod`
- `ENGINE_AUTH_MODE=strict`
- `ENGINE_API_MODE=idl`

Sem atalhos e com testes E2E/Proof offline como hard gates.

Comece por `docs/specs/expansao/00-plano.md`.
