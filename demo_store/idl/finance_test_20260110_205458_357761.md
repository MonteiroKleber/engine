## System

- **ID:** finance
- **Name:** Financial Management System
- **Description:** Manages accounts, transactions, invoices and reports
- **Version:** 1.0.0
- **Domain:** finance

## Actors

### accountant (human)

- **Name:** Contador
- **Description:** Profissional de contabilidade
- **Permissions:** create_transactions, manage_invoices, view_accounts, view_reports
- **Authentication:** token

### admin (human)

- **Name:** Administrador
- **Description:** Usuário administrador do sistema financeiro
- **Permissions:** manage_accounts, manage_budgets, manage_invoices, manage_transactions, view_reports
- **Authentication:** token

### viewer (human)

- **Name:** Visualizador
- **Description:** Usuário com acesso somente leitura
- **Permissions:** view_accounts, view_invoices, view_reports, view_transactions
- **Authentication:** basic

**Indexes:**

### Budget

**Fields:**
- `amount`: decimal [required]
- `category`: string [required]
- `created_at`: datetime [required]
- `id`: uuid [required, unique]
- `period_end`: datetime [required]
- `period_start`: datetime [required]
- `spent`: decimal

**Relations:**
- `account` -> Account (belongs_to)

- `valid_period`: period_end > period_start

**Indexes:**
- `idx_category` on (category)
- `idx_period` on (period_start, period_end)

### Invoice

**Fields:**
- `created_at`: datetime [required]
- `currency`: string
- `customer_email`: string
- `customer_name`: string [required]
- `due_date`: datetime [required]
- `id`: uuid [required, unique]
- `invoice_number`: string [required, unique]
- `issued_at`: datetime
- `paid_at`: datetime
- `status`: string
- `subtotal`: decimal [required]
- `tax_amount`: decimal
- `total`: decimal [required]

**Relations:**

**Constraints:**
- `total_calculation`: total = subtotal + tax_amount

**Indexes:**
- `idx_due_date` on (due_date)
- `idx_status` on (status)

### InvoiceItem

**Fields:**
- `created_at`: datetime [required]
- `description`: string [required]
- `id`: uuid [required, unique]
- `quantity`: int
- `total`: decimal [required]
- `unit_price`: decimal [required]

**Relations:**
- `invoice` -> Invoice (belongs_to)

**Constraints:**
- `item_total`: total = quantity * unit_price

### Transaction

- `id`: uuid [required, unique]

## Use Cases

### create_account: Criar Conta

Permite criar uma nova conta financeira

- **Actors:** admin
- **Priority:** high
- **Complexity:** simple

**Preconditions:**
- Usuário autenticado
- Permissão manage_accounts

**Main Flow:**
1. Usuário acessa formulário de criação
2. Usuário preenche dados da conta (nome, tipo, moeda)
3. Sistema valida dados
4. Sistema cria conta com saldo zero
5. Sistema retorna confirmação

**Postconditions:**
- Conta criada com saldo inicial
- Registro de auditoria gerado

### create_invoice: Emitir Fatura

Permite criar e emitir uma fatura para cliente

- **Actors:** accountant, admin
- **Priority:** high
- **Complexity:** medium

**Preconditions:**
- Usuário autenticado
- Cliente identificado

**Main Flow:**
1. Usuário inicia criação de fatura
2. Usuário informa dados do cliente
3. Usuário adiciona itens
4. Sistema calcula subtotal e impostos
5. Sistema calcula total
6. Usuário confirma emissão
7. Sistema gera número da fatura
8. Sistema salva fatura como SENT

**Postconditions:**
- Fatura criada
- Número único gerado
- Status DRAFT

### create_transaction: Registrar Transação

Permite registrar uma nova transação financeira

- **Actors:** accountant, admin
- **Priority:** critical
- **Complexity:** medium

**Preconditions:**
- Usuário autenticado
- Contas existentes
- Saldo disponível para débito

**Main Flow:**
1. Usuário seleciona tipo de transação
2. Usuário informa contas origem/destino
3. Usuário informa valor e descrição
4. Sistema valida saldo disponível
5. Sistema registra transação como PENDING
6. Sistema processa transação
7. Sistema atualiza saldos
8. Sistema marca transação como COMPLETED

**Postconditions:**
- Transação registrada
- Saldos atualizados
- Auditoria gerada

### generate_report: Gerar Relatório

Gera relatórios financeiros consolidados

- **Actors:** accountant, admin, viewer
- **Priority:** medium
- **Complexity:** complex

**Preconditions:**
- Usuário autenticado
- Período selecionado

**Main Flow:**
1. Usuário seleciona tipo de relatório
2. Usuário define período
3. Usuário aplica filtros opcionais
4. Sistema processa dados
5. Sistema gera relatório
6. Sistema exibe resultado

**Postconditions:**
- Relatório gerado
- Dados consolidados

### manage_budget: Gerenciar Orçamento

Permite criar e monitorar orçamentos por categoria

- **Actors:** admin
- **Priority:** medium
- **Complexity:** simple

**Preconditions:**
- Usuário autenticado
- Conta vinculada

**Main Flow:**
1. Usuário seleciona conta
2. Usuário define categoria e período
3. Usuário define valor do orçamento
4. Sistema cria orçamento
5. Sistema monitora gastos automaticamente

**Postconditions:**
- Orçamento definido
- Alertas configurados

## Non-Functional Requirements

### data_protection: Proteção de Dados (security)

Dados financeiros devem ser protegidos

- **Priority:** critical
- **Metric:** encryption_coverage
- **Target:** 100%
- **Measurement:** Dados sensíveis criptografados em trânsito e repouso
- **Verification:** Auditoria de segurança

### financial_audit: Conformidade Financeira (compliance)

Sistema deve atender requisitos de auditoria

- **Priority:** critical
- **Metric:** audit_trail_completeness
- **Target:** 100%
- **Measurement:** Todas as operações registradas com timestamp e usuário
- **Verification:** Auditoria externa anual

### response_time: Tempo de Resposta (performance)

API deve responder em tempo aceitável

- **Priority:** high
- **Metric:** response_time_p99
- **Target:** < 500ms
- **Measurement:** Percentil 99 do tempo de resposta
- **Verification:** Testes de carga com k6

### uptime: Disponibilidade (availability)

Sistema deve estar disponível

- **Priority:** high
- **Metric:** uptime_percentage
- **Target:** 99.9%
- **Measurement:** Tempo de atividade mensal
- **Verification:** Monitoramento contínuo
